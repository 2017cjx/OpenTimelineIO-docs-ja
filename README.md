# OpenTimelineIO 非公式日本語ドキュメント

[OpenTimelineIO](https://github.com/AcademySoftwareFoundation/OpenTimelineIO) 公式ドキュメントの**非公式**日本語訳リポジトリです。

Academy Software Foundation / OpenTimelineIO プロジェクトの公式翻訳ではありません。

## 方針

- 訳文は手書きで書く（機械翻訳・生成 AI による下訳は使わない）
- 英語の正本は常に upstream の `docs/`
- このリポジトリは学習・共有用。upstream 本体へのマージを前提にしない

## ディレクトリ

原文（ローカルに clone している場合）との対応:

| このリポジトリ | 原文 |
|----------------|------|
| `docs/tutorials/` | `OpenTimelineIO/docs/tutorials/` |
| `docs/use-cases/` | `OpenTimelineIO/docs/use-cases/` |

進捗は [TRANSLATION_STATUS.md](./TRANSLATION_STATUS.md) を更新する。  
追従している upstream のコミットは [UPSTREAM.md](./UPSTREAM.md) を見る。

## 訳を足すとき

1. `UPSTREAM.md` のコミットで原文を開く
2. 同名の `.md` を `docs/` 以下に作る
3. 冒頭に「原文リンク・対象コミット・非公式である旨」を書く
4. `TRANSLATION_STATUS.md` を更新する
